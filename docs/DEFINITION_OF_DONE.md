# Definition of Done

Bir görev veya proje aşağıdaki şartlar sağlanmadan tamamlanmış sayılmaz.

## Görev seviyesinde

- Kabul kriterleri karşılandı.
- Birim testleri geçti.
- İlgili entegrasyon testleri geçti.
- Lint ve type-check geçti.
- Yetkisiz dosya değişikliği yok.
- Korunan testler değiştirilmedi.
- Güvenlik kontrolünde kritik bulgu yok.
- Değişiklik ayrı commit olarak kaydedildi.
- Bilinen sınırlamalar yazıldı.

## Proje seviyesinde

- Zorunlu özellikler tamamlandı.
- Tüm kabul testleri geçti.
- Kurulum sıfırdan doğrulandı.
- Uygulama örnek senaryoda çalıştırıldı.
- Dokümantasyon tamamlandı.
- Secret veya kişisel veri sızıntısı bulunmadı.
- Geri alma planı mevcut.
- Kullanıcı kabulü alındı.
- Final teslimat raporu oluşturuldu.
